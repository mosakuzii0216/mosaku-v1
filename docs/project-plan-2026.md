# Mosaku プロジェクト計画（2026年3月〜12月）

作成日: 2026-03-14
最終更新: 2026-03-14

---

## 方針・前提

| 項目               | 決定事項                                                                        |
| ------------------ | ------------------------------------------------------------------------------- |
| 登録方式           | **招待制を永続維持**。招待コードをDMに含めて営業する形式                        |
| 権限モデル         | **ADMIN / USER の2種類のみ**（PREMIUMロール廃止）                               |
| 招待コード種別     | **通常コード**（1回使い切り）と**キャンペーンコード**（1コードでN名まで登録可） |
| 収益化             | 友人フェーズまで完全無料。友人ヒアリング後にノートブック買い切りモデルを判断    |
| フィードバック     | アプリ内フォーム → Slack通知                                                    |
| ランディングページ | デザイン・テーマのショーケースを前面に出した視覚重視のLP                        |
| SNS営業チャネル    | **X（Twitter）** + **Instagram**（両方新規アカウント作成）                      |
| 差別化軸           | **ハイセンスなデザイン・テーマ数の多さ・ブランディングの雰囲気**                |
| テーマ目標         | **50テーマ**（現在7、43追加。週5時間込みで現実的な数）                          |
| 障害対応           | Sentryエラー検知 → AIが自動で初期調査しSlack通知 → 必要なら即時対応             |
| 開発ペース         | **週5時間**（月約20時間、テーマ作成込み）                                       |

**AI障害自動調査パイプライン:**

```
Sentry エラー検知
  → Webhook → Claude API でエラーログを解析
      - 原因仮説・影響範囲・緊急度を自動判定
  → Slack に調査結果を投稿
      - critical: @channel アラート
      - warning: 通常通知
```

## 実装タスク優先度マップ

```
【リリース必須（〜4月）】
├── 自動保存
├── ゴミ箱機能（Soft Delete）
└── PREMIUMロール廃止

【友人公開必須（〜9月）】
├── 利用規約・プライバシーポリシー
├── アカウント削除機能
├── アプリ内フィードバックフォーム + Slack連携
├── AI障害自動調査パイプライン（Sentry + Claude API）
└── ランディングページ

【差別化・コンテンツ（継続）】
├── テーマ追加（目標: 50テーマ、月2〜10本ペース）
└── SNSコンテンツ制作（テーマ完成と連動）

【後回し可】
├── 収益化（Stripe連携）- 友人ヒアリング後に判断
├── データエクスポート
├── キャンペーンコード管理UI
└── 高難度機能（メモ間リンク・共有等）
```
