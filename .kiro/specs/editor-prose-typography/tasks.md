# Implementation Plan

- [x] 1. Typography プラグイン導入と prose の有効化・調整
- [x] 1.1 @tailwindcss/typography の導入とプラグイン登録
  - frontend の開発依存に `@tailwindcss/typography`（Tailwind v3 互換の `^0.5.19`）を追加する
  - Tailwind 設定のプラグイン一覧へ typography を登録し、`prose` クラスがブロック要素スタイルを生成する状態にする
  - 既存の content グロブ・darkMode・theme.extend を変更せず、ビルドが通ることを確認する
  - _Requirements: 1.1, 1.2, 1.3, 1.4_
- [x] 1.2 prose 既定スタイルの調整（衝突回避・レイアウト維持）
  - editor / public 共有の単一 typography 設定として、インラインコードのバッククォート擬似要素を無効化する
  - コードブロック（pre / code）の prose 既定配色・余白を無効化し、既存コードハイライトの表示を優先させる
  - タスクリストの行頭バレット・インデントを抑止し、チェックボックス表示と二重化させない
  - 本文幅の中央寄せ制限（max-width）を解除して現行レイアウトを維持する
  - 本文色を維持しつつ、見出し・リンク色を地色・テーマ背景と衝突しない値に整える
  - 見出し・リスト・引用が、ツールバー / input rules / スラッシュコマンドのいずれで生成しても等価に視覚化されることをローカル実機で確認する
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5, 3.1, 3.2, 3.3, 4.1, 4.2, 4.3, 4.4, 5.1, 5.2, 5.3_

- [x] 2. (P) prose 有効化の回帰ガードテスト
  - Tailwind 設定に typography プラグインが登録されていることを検証する
  - エディタと公開メモビューのレンダリング要素が prose クラスを保持していることを検証する（クラス撤去による退行の防止）
  - _Requirements: 1.2, 6.2_

- [x] 3. 実描画の視覚検証（Playwright）
- [x] 3.1 エディタのブロック要素 computed style 検証
  - 見出しを入力後、見出しのフォントサイズが本文段落より大きいことを検証する
  - 箇条書き・番号付きリストの行頭記号（list-style-type が none 以外）が描画されることを検証する
  - 引用ブロックに左罫線または左パディングが付与されることを検証する
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 6.2, 6.3_
- [x] 3.2 公開メモビューの対称検証と既存機能の非競合
  - 同一保存 HTML に対し、公開メモビューでも見出し・リスト・引用がエディタと一致して視覚化されることを検証する
  - コードブロックがハイライトされ、pre 背景が既存コードハイライトの配色のままであることを検証する
  - タスクリスト項目にバレットが出ないことを検証する
  - _Requirements: 3.1, 3.2, 4.1, 4.2, 6.4_

- [x] 4. 非回帰の最終確認
  - frontend の全テストスイート（現状 757 件）が成功することを確認する
  - lint・型チェックが通ることを確認する
  - _Requirements: 6.1_
