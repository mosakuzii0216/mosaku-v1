# Requirements Document

## Introduction

メモ表示モード（フォーカス/没入表示）は、Mosaku のメモ詳細・編集画面に追加するリードオンリーの全画面表示機能である。ユーザーが書いたメモに静かに向き合える没入体験を提供し、将来の習慣化機能（デイリープロンプト・AI 下書き）との連携基盤となる。実装は Frontend（React + Vite）中心で、UI 状態は Zustand、サーバーデータは React Query から参照し、テーマは既存 CSS 変数システムに準拠する。

---

## Requirements

### Requirement 1: 表示モードの起動

**Objective:** As a メモを書いたユーザー, I want メモ詳細・編集画面から表示モードを 1 アクションで起動したい, so that 書いた内容にすぐに没入できる

#### Acceptance Criteria

1. When ユーザーがメモ詳細または編集画面で表示モード起動ボタン（またはトグル）をクリックしたとき, the 表示モード機能 shall 表示モードを起動しアプリ内全画面オーバーレイを表示する
2. When 表示モードを起動したとき, the 表示モード機能 shall React Query のキャッシュから既存のメモデータを参照し、API を追加呼び出しせずにコンテンツを表示する
3. The 表示モード機能 shall 起動ボタン/トグルをメモ詳細画面・編集画面の両方からアクセスできる位置に配置する
4. The 表示モード機能 shall 表示モードの開閉状態を Zustand の UI ストア（`useViewStore` または専用ストア）で管理し、サーバーデータのコピーを行わない

---

### Requirement 2: 没入型フルスクリーン表示レイアウト

**Objective:** As a メモを振り返るユーザー, I want 本文が全画面で読みやすく表示されたい, so that 文章に集中できる没入体験が得られる

#### Acceptance Criteria

1. While 表示モードが起動しているとき, the 表示モード機能 shall コンテンツエリアをビューポート全体（100vw × 100vh）にオーバーレイ表示する
2. While 表示モードが起動しているとき, the 表示モード機能 shall メモ本文を水平中央寄せ・横幅最大 65ch 程度の読みやすいカラム幅で縦スクロール可能なレイアウトで表示する
3. While 表示モードが起動しているとき, the 表示モード機能 shall メモタイトルを本文より大きなフォントサイズで本文上部に表示する
4. While 表示モードが起動しているとき, the 表示モード機能 shall サイドバー・ツールバー・エディタ操作 UI など通常画面の UI 要素を非表示にする
5. The 表示モード機能 shall 読みやすさのために行間（`line-height` 1.8 以上）・本文フォントサイズ（18px 以上）を通常編集画面より大きく設定する

---

### Requirement 3: リードオンリーコンテンツ表示

**Objective:** As a メモを振り返るユーザー, I want 誤って編集してしまわない安心感を得たい, so that 読むことだけに集中できる

#### Acceptance Criteria

1. While 表示モードが起動しているとき, the 表示モード機能 shall メモ本文を編集不可のリードオンリー状態でレンダリングする
2. While 表示モードが起動しているとき, the 表示モード機能 shall TipTap の `editable: false` モードまたは既存の読み取り専用レンダラー（`PublicMemoRenderer`）を使ってリッチテキストコンテンツをレンダリングする
3. While 表示モードが起動しているとき, the 表示モード機能 shall テキスト選択・コピーを可能にする
4. If メモの本文が空のとき, the 表示モード機能 shall 空状態を示すメッセージまたはビジュアルを表示する

---

### Requirement 4: 表示モードの終了

**Objective:** As a 表示モードを使ったユーザー, I want 直感的に通常表示へ戻れたい, so that 編集や他の操作にスムーズに移行できる

#### Acceptance Criteria

1. When ユーザーが ESC キーを押したとき, the 表示モード機能 shall 表示モードを終了し直前の画面（メモ詳細または編集画面）へ復帰する
2. When ユーザーが表示モード内の「閉じる」ボタンをクリックしたとき, the 表示モード機能 shall 表示モードを終了し直前の画面へ復帰する
3. When ユーザーがオーバーレイの背景（コンテンツ外エリア）をクリックしたとき, the 表示モード機能 shall 表示モードを終了する
4. While 表示モードが起動しているとき, the 表示モード機能 shall 閉じるボタンをオーバーレイ上の常に視認可能な位置（右上など）に表示する

---

### Requirement 5: テーマ・スタイル整合性

**Objective:** As a テーマを設定しているユーザー, I want 表示モードでも選んだテーマが反映されたい, so that アプリの世界観を壊さずに没入できる

#### Acceptance Criteria

1. While 表示モードが起動しているとき, the 表示モード機能 shall 現在アクティブなテーマの CSS 変数（色・フォント等）を表示モードのスタイルに適用する
2. The 表示モード機能 shall テーマごとの CSS 変数（`--color-background`・`--color-text` 等）を上書きせず参照することで、テーマ変更に自動追随する
3. Where テーマにエフェクト（`effectKey`）が設定されているとき, the 表示モード機能 shall テーマエフェクトを表示モード中も継続して表示する（表示モード中はエディタフォーカスが外れるため、エフェクトの自動停止条件に抵触しない）
4. The 表示モード機能 shall 表示モード専用の読みやすさ向上スタイル（フォントサイズ・行間等）を CSS カスタムプロパティで定義し、テーマ側から上書き可能な設計にする
