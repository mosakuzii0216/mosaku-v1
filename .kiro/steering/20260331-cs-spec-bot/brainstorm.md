## 有力候補

### CS仕様問い合わせBot

**アーキテクチャ:**

```
n8n（定期実行: cron）
        ↓
  社内システムAPI をポーリング（新規問い合わせを取得）
        ↓ 新規あれば
  Claude SDK Agent（社内サーバ上）
  ├── 質問を解析
  ├── search_codebase（grep）
  ├── read_file（関連ファイル読む）
  └── 回答案を生成
        ↓
  Mattermost or GitHub Issue に投稿
  「回答案: ○○ / 参照ファイル: △△:行番号」
        ↓
  開発者レビュー → 手動返信
```

**前提条件:**

- 社内サーバに mosaku リポジトリが clone されている
- Claude SDK Agent がそのパスにアクセスできる
- Mattermost webhook URL or GitHub Token が必要

**未決事項:**

- レビュー通知先: Mattermost か GitHub Issue かは未決

**理由:** 毎日3回の手動作業を自動化できる。完全自動ではなく開発者レビューを挟む設計なので、誤回答リスクも低い。
