# Dogfooding 運用ルール（Phase 1 限定）

Phase 1 ドッグフーディング期間中、Mosaku を本人の日常メモ用ツールとして使い、摩擦を記録するための運用ルール。Phase 1 終了時にこのファイルは削除する。

開始日: 2026-05-21

## Friction Log ノートブック

- ノートブック名: `Friction Log`
- 用途: Mosaku を使っていて感じた摩擦・違和感・不具合・改善アイデアを 1 メモ = 1 摩擦で記録する
- 1 メモのテンプレート:
  - タイトル: 摩擦の要約（30 字以内）
  - 本文: 状況 / 期待した動作 / 実際の動作 / 影響度の所感
  - タグ: 後述の命名規約に従う

## タグ命名規約

| タグ         | 意味                                   | 使いどころ                       |
| ------------ | -------------------------------------- | -------------------------------- |
| `#blocker`   | 作業を止める致命的な摩擦               | データロスト・継続利用不可レベル |
| `#major`     | 致命ではないが頻繁に当たって辛い摩擦   | 体験を大きく損なうもの           |
| `#minor`     | 気になるが我慢できる摩擦               | 細かい改善要望                   |
| `#spec-done` | 摩擦に対する spec が完了して解消された | トリアージ時に付け替える         |

`#blocker` と `#major` のみが spec 化の検討対象。`#minor` は溜める。

## 金曜トリアージ

毎週金曜に Friction Log を見直す（所要 15 分目安）。

1. 今週追加された未トリアージのメモに `#blocker` / `#major` / `#minor` のいずれかを付ける
2. `#blocker` が 1 件でもあれば、即座に `/kiro:spec-init` で起票して翌週着手
3. `#blocker` が無ければ `#major` から件数最多 or 影響最大の 1 件を Top1 として選定し `/kiro:spec-init`
4. spec 化されたメモには `#spec-being-handled` を追加（重複起票防止）。spec が `completed` または `implementation-validated` に到達したら `#spec-done` に付け替える

## 運用上の注意

- Notion など他のメモツールは Phase 1 期間中は閉じる。Mosaku を唯一のメモ環境にすることで摩擦が浮上する
- 摩擦記録自体に時間をかけすぎない。30 秒〜2 分で書き留める粒度を維持する
- 摩擦が見つからない週があっても問題ない。無理に書かない

## 終了条件

以下のいずれかを満たした時点で本ファイルを削除し、Phase 2 へ移行する:

- 友人・知人公開（10 月マイルストーン）の直前
- 1 ヶ月以上 `#blocker` / `#major` が 0 件で安定
