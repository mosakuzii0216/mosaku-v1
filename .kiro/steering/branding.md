# Branding

Mosaku（模索）の世界観の最上流。テーマ・LP・コピーは全てここから派生させる。

## ブランドの核

**模索 = 「人生という冒険を進めていく上で、道標になるようなものを書き留めておく場所」。** 単に「模索する」より一歩踏み込んだ意味。作者のハンドル `devmosaku` の由来でもある、それくらい好きな言葉。

扱うのは「人生の指針・物語」であって「情報・記録」ではない。

## ポジショニング

| プロダクト | 主軸                                     |
| ---------- | ---------------------------------------- |
| Notion     | 整理する                                 |
| Obsidian   | つなぐ                                   |
| iA Writer  | 集中する                                 |

| **Mosaku** | **人生の道標を書き留める（指針・物語）** |

機能の豊富さではなく「書きたくなる世界観」で勝負する。

## テーマ哲学

各テーマ = 「冒険の異なる風景」。ビジュアルモチーフ: 道標 / 羅針盤 / 北極星 / 地図 / 灯台 / 足跡 / 道。

**和の4テーマ**（2026-06-20 に旧15テーマから集約。量産した色替えテンプレを捨て「量より質」へ転換）:

| テーマ     | 冒険の局面               | 世界観                               | 色  |
| ---------- | ------------------------ | ------------------------------------ | --- |
| mori（森） | 分け入る・思索           | 深緑・閉じた深さ（お手本テーマ）     | 緑  |
| umi（海）  | 漕ぎ出す・見渡す         | 深い海中・没入                       | 青  |
| yoru（夜） | 立ち止まり星を読む・内省 | 墨夜の静寂・ミニマル（北極星＝道標） | 藍  |
| asa（朝）  | 踏み出す・始まり         | 朝焼け・希望（セット唯一の明テーマ） | 橙  |

4つで「冒険の一日（＝人生の縮図）」が巡る。森→海→夜→朝。

## 深掘りの型（全テーマ共通。新規テーマもこれを踏襲し、安易な色替えはしない）

1. 生きた背景（animated gradient、`background-size: 400%` + keyframes）
2. 大気レイヤー（`::before` / `::after` = 霧 / 光線 / 星 / 朝日）
3. 游明朝 ＝ ブランド共通の署名フォント
4. 引き算（`box-shadow` 撤去＝浮いたカードでなく一面の世界に没入）
5. 可読性（暗テーマ＝明文字＋`text-shadow` / 明テーマ＝濃文字）
6. `prefers-reduced-motion` で動き停止・パレットは維持

代表テーマ `mori` のみ JS エフェクト基盤（`metadata.effectKey` + `ParticleCanvas`）を持つ。umi / yoru / asa への展開は phase-2（未着手）。
