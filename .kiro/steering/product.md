# Product Overview

Mosakuは、招待制のマルチユーザーメモ・ノートブックアプリ。**デザインの美しさ・テーマの多様性**を差別化軸とし、書くことが好きな日本語圏のユーザーに向けて提供する。

## Core Capabilities

1. **メモ・ノートブック管理**: リッチテキストエディタ（TipTap）による作成・編集・タグ分類
2. **テーマシステム**: CSS変数ベースの多数テーマ（目標50）。ユーザーが自由に切り替え・お気に入り登録
3. **招待制アクセス**: 招待コードによるユーザー登録。通常コード（1回）とキャンペーンコード（N人まで）の2種類
4. **JWT + OAuth認証**: メール/パスワードと Google・GitHub OAuth に対応

## Target Use Cases

- 日々のメモ・アイデアの記録（テーマで気分を変えながら書く）
- ノートブックによるテーマ別コンテンツ整理
- タグを横断した情報管理

## Value Proposition

「使いたくなるデザイン」が軸。Notionのような機能重視ではなく、**見た目の美しさと雰囲気**でユーザーが自分のスペースに愛着を持てるツール。招待制により品質を保った小規模コミュニティを志向する。
