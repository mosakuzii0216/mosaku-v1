# Product Overview

Mosakuは、招待制のマルチユーザーメモ・ノートブックアプリ。**テーマの芸術性**を差別化軸とし、書くことが好きな日本語圏のユーザーに向けて提供する。

> **差別化軸の定義（2026-08-12 確定）**: 旧「テーマの多様性（数の多さ）」から **「テーマの芸術性（作家性）」** へ転換。
> 根拠: AI により平均的な実装物のコストが限りなく下がる時代において、**「この作り手にしか出せない世界観」だけが代替不能な資産になる**という読み。
> 帰結: テーマは**数を追わない**。1テーマあたりの深さ（世界観・大気・質感・没入）に投資する。2026-06-20 の和4テーマ集約はこの軸と整合する。安易な色替えは禁止。

## Core Capabilities

1. **メモ・ノートブック管理**: リッチテキストエディタ（TipTap）による作成・編集・タグ分類
2. **テーマシステム**: CSS変数ベースの**和の4テーマ**（`mori` 森 / `umi` 海 / `yoru` 夜 / `asa` 朝）。2026-06-20 に旧15テーマから「量より質」へ集約し、4つで「人生という冒険の一日」が完結する arc を成す。ユーザーが自由に切り替え・お気に入り登録。**全4テーマ**がテーマエフェクト基盤を介して背景アニメーション・パーティクル等の JS エフェクトを動的ロード（選択時のみロード。モバイルは無効）
3. **招待制アクセス**: 招待コードによるユーザー登録。通常コード（1回）とキャンペーンコード（N人まで）の2種類
4. **JWT + OAuth認証**: メール/パスワードと **Google・X・Apple** の 3 プロバイダに対応（LINE / GitHub は `oauth-providers-reduction` で 2026-07-21 に廃止）。全プロバイダ PKCE/AEAD ステートレス方式で統一（passport 撤去済み）
5. **自動保存**: 編集停止後2秒でサーバーへ自動保存。5状態インジケーター（idle/pending/saving/saved/error）
6. **ゴミ箱（Soft Delete）**: 削除メモを30日間保持。復元・完全削除・ゴミ箱を空にする操作に対応

## Target Use Cases

- 日々のメモ・アイデアの記録（テーマで気分を変えながら書く）
- ノートブックによるテーマ別コンテンツ整理
- タグを横断した情報管理

## Value Proposition

「使いたくなるデザイン」が軸。Notionのような機能重視ではなく、**作り手の世界観が宿ったテーマ**でユーザーが自分のスペースに愛着を持てるツール。汎用テンプレートでは再現できない芸術性そのものが競争優位となる。代表テーマ `mori`（深緑の森ブランドテーマ）はログイン画面と統一されたブランド表現で、ユーザーが「このアプリの世界観」を最初に体感する役割を担う。招待制により品質を保った小規模コミュニティを志向する。
