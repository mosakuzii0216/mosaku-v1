# Product Overview

Mosakuは、招待制のマルチユーザーメモ・ノートブックアプリ。**デザインの美しさ・テーマの多様性**を差別化軸とし、書くことが好きな日本語圏のユーザーに向けて提供する。

## Core Capabilities

1. **メモ・ノートブック管理**: リッチテキストエディタ（TipTap）による作成・編集・タグ分類
2. **テーマシステム**: CSS変数ベースの多数テーマ（目標50）。ユーザーが自由に切り替え・お気に入り登録。一部テーマ（`mori`）はテーマエフェクト基盤を介して背景アニメーション・パーティクル等の JS エフェクトを動的ロード（非エフェクトテーマには影響しない）
3. **招待制アクセス**: 招待コードによるユーザー登録。通常コード（1回）とキャンペーンコード（N人まで）の2種類
4. **JWT + OAuth認証**: メール/パスワードと Google・GitHub・LINE・Apple・X OAuth に対応
5. **自動保存**: 編集停止後2秒でサーバーへ自動保存。5状態インジケーター（idle/pending/saving/saved/error）
6. **ゴミ箱（Soft Delete）**: 削除メモを30日間保持。復元・完全削除・ゴミ箱を空にする操作に対応

## Target Use Cases

- 日々のメモ・アイデアの記録（テーマで気分を変えながら書く）
- ノートブックによるテーマ別コンテンツ整理
- タグを横断した情報管理

## Value Proposition

「使いたくなるデザイン」が軸。Notionのような機能重視ではなく、**見た目の美しさと雰囲気**でユーザーが自分のスペースに愛着を持てるツール。代表テーマ `mori`（深緑の森ブランドテーマ）はログイン画面と統一されたブランド表現で、ユーザーが「このアプリの世界観」を最初に体感する役割を担う。招待制により品質を保った小規模コミュニティを志向する。
