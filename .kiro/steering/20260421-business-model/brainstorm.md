## 確定事項

### 料金体系

```
【無料】
├── メモ: 無制限（ノートブック外もOK）
├── ノートブック: 3冊まで（各3万文字上限）
├── テーマ: 全テーマ無料・変更自由
└── AI: 使えない

【買い切り】
├── ノートブック単品: 1冊100円（3万文字、AI付き）
├── ノートブックパック:
│     5冊  300円（1冊60円）
│     10冊 500円（1冊50円）
│     15冊 700円（1冊47円）
│     20冊 900円（1冊45円）
└── AI: 購入したノートブック内でのみ使える（月30回/冊）

【サブスク】
└── 月額500円
      ├── 全ノートブック（無料3冊含む）で AI 使える（月100回）
      └── 毎月ノートブック1冊付与（繰り越しあり）
```

### ルール

- テーマは全ユーザー全テーマ無料
- ノートブックのテーマは後から自由に変更可能
- ノートブックの文字上限: 3万文字（無料・有料共通）
- 容量は「今入ってるメモの合計」で判定（メモを外せば空く）
- ノートブック外のメモでは AI 使えない
- 決済は Stripe（買い切り: Payment Intent / サブスク: Subscription）

### サブスクの詳細ルール

- 毎月1冊のノートブック作成権が付与される
- 未使用分は繰り越しあり（上限なし）
- 一度作ったノートブックは解約後も残る（読み書きOK）
- 解約後: AI 機能は全ノートブックで使えなくなる（買い切り分含む）
- 買い切りノートブックも解約後は読み書きのみ（AI不可）

### AI 機能（確定）

**第1弾 MVP:**

| 機能               | 操作方法                           | 結果の表示                                    |
| ------------------ | ---------------------------------- | --------------------------------------------- |
| 推敲・校正         | スラッシュコマンド `/ai-proofread` | 修正案を提示 → ユーザーが「適用」ボタンで反映 |
| 要約               | スラッシュコマンド `/ai-summarize` | エディタ内にインライン表示                    |
| ノートブック内 Q&A | `/ai-ask` or サイドパネルアイコン  | サイドチャットパネルで対話                    |

**第2弾以降（将来）:**

- タグの自動提案
- 続きを書く（文章生成）
- メモの自動分類

**利用上限:**

- 買い切りノートブック: そのノートブック内で月30回
- サブスク: 全体で月100回

**UI 設計:**

```
┌─────────────────────────────────────────┐
│   メモエディタ                             │
│                                         │
│   /ai-proofread                         │
│   ┌─────────────────────────┐           │
│   │ /ai-proofread  推敲・校正 │           │
│   │ /ai-summarize  要約      │           │
│   │ /ai-ask        AIに質問   │           │
│   └─────────────────────────┘           │

                              ┌──────────┐
```

- 普段はサイドパネル非表示（テーマのデザイン性優先）
- スラッシュコマンドでエディタ内完結する操作（推敲・要約）
- サイドチャットで対話的な操作（Q&A、自由な質問）
- 推敲・校正: 修正案を提示し「適用」ボタンで反映（GitHub Copilot 風）

### DB設計（方向性）

```
User
  + stripeCustomerId       String?
  + subscriptionStatus     NONE | ACTIVE | CANCELED | EXPIRED
  + subscriptionExpiresAt  DateTime?
  + notebookCredits        Int @default(0)  // サブスク付与の未使用分

Notebook（既存を拡張）
  + characterLimit         Int      @default(30000)
  + isFree                 Boolean  @default(true)
  + purchaseId             String?  → Purchase

Purchase（新規）
  id
  userId          → User
  type            SINGLE_NOTEBOOK | NOTEBOOK_PACK | SUBSCRIPTION
  amount          Int
  currency        "jpy"
  status          PENDING | COMPLETED | FAILED | REFUNDED
  stripePaymentIntentId   String?
  stripeSubscriptionId    String?
  createdAt

AiUsage（新規 - AI利用量トラッキング）
  id
  userId          → User
  notebookId      → Notebook
  action          String    // "proofread" | "summarize" | "qa"
  tokensUsed      Int
  createdAt

Theme（変更なし）
  ※ テーマ課金は行わない。全テーマ無料。
```

## 設計思想

- 「書くこと自体は自由、見た目は全員に、AIに課金」
- ユーザーにストレスを与える制限は最小限に
- 物理ノートの比喩: ノートを使い切ったら新しいのを買う感覚
- 招待制の小規模コミュニティだから、客単価で収益を確保する
- メモの習慣化を促進する設計（サブスクで毎月付与 → 使わなきゃもったいない）
- 打倒 Notion: 月500円で AI 付きは Notion AI（月$10）の1/3以下
- テーマのデザイン性を最優先（AI の UI は普段は隠れている）

### spec-init の実行計画

機能が大きいため、3つの spec に分割して順番に進める:

```bash
# 1. ノートブック課金（最初にやる。DBスキーマ変更が全てのベース）
/kiro:spec-init "ノートブック買い切り課金（Stripe連携・文字数制限・パック販売）"

# 2. サブスク（1の上に構築）
/kiro:spec-init "月額サブスク（Stripe Subscription・AI全解放・毎月ノートブック付与）"

# 3. AI 機能（1+2の上に構築）
/kiro:spec-init "AI機能第1弾（推敲・要約・Q&A・スラッシュコマンド・サイドチャット）"
```

各 spec は cc-sdd フローに従う:

```
/kiro:spec-init → /kiro:spec-requirements → 承認
  → /kiro:spec-design → 承認
  → /kiro:spec-tasks → 承認
  → /kiro:spec-impl（タスク番号）→ TDD で実装
  → /kiro:validate-impl で整合性確認
  → コミット
```
