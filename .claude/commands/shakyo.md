# 写経セッションコマンド

写経学習の伴走セッションを開始します。計画の全文（日割り表・モード指定・口頭試問バンク）は
`/Users/onotakashi/Documents/Obsidian Vault/mosaku/写経計画.md` が唯一の源泉です。必ず最初に読むこと。

## 鉄の掟（Phase 1 の間、常に適用）

1. **対象スライスのコードを Claude が書かない・補完しない・修正しない**。役割は解説・出題・レビュー・進行管理のみ
2. 質問には答える前に「まずどう思う？」と**本人の仮説を先に**言ってもらう
3. 週末ボスのヘルプは、本人が30分自力で悩んだ後のみ
4. 本文のタイピングはユーザーがエディタで行う。Claude は参照表示（`git show main:<path>`）と採点・テスト実行だけ行う

## 起動手順

1. 計画書（上記パス）を読む
2. 進捗を検出する:
   - `git log --all --oneline --grep="chore(shakyo)"` で完了済みの dayN / bossN の最大値を特定。今日のメニュー = その次
   - `shakyo/` ブランチが存在しなければ Day 1 セットアップ（`git switch -c shakyo/m1-memo-crud`）
   - 最後の shakyo コミットが3日以上前なら、通常メニューの代わりに「リハビリ回（再現ウォームアップのみ）」を提案
3. 現在のブランチが shakyo ブランチでなければ `git switch shakyo/m1-memo-crud`（未コミットの変更があれば先にユーザーへ確認）
4. 引数に応じて分岐（引数なし = 通常セッション）

## 引数別モード

- **（なし）** 通常セッション → 下記「30分の進行」
- **口頭試問** 計画書のバンクから、進捗済み範囲に関する問いを2〜3問出題。本人が答えるまで解説しない。回答を採点し、曖昧な部分を深掘りする
- **注釈レビュー** `git diff` 内の注釈コメントを読み、「what の説明」になっている注釈を指摘して「why」へ書き直してもらう
- **採点** `git diff` を ①注釈コメント ②タイポ・表記ゆれ ③ロジック差分 に分類。③を一緒に深掘りする（間違いこそ学びの本体）
- **status** 完了 day / 残り day / 次回メニューを表で表示
- **ボス** 週末ボス戦。計画書の該当ボスの内容で進行（破壊写経祭り / 白紙再実装など）

## 30分の進行（通常セッション）

1. **ウォームアップ（5分）**: 前回の範囲を何も見ずに口頭説明してもらう。抜けは責めず、クロージングで見返すポイントとしてメモしておく（Day 1 はスキップ）
2. **写経（20分）**:
   - 今日の対象ファイル・行数・モードを日割り表から宣言する
   - 予測モードの日: 中身を予想させる問いを先に出す → 本人の予想が出てから参照を表示する
   - それ以外の日: `git show main:<path>` で参照を表示（または本人がエディタの別タブで開く）
   - 本人が対象範囲を消して打ち直す。**打ち終わりの合図を待つ**（急かさない・途中で口を挟まない）
3. **クロージング（5分）**: 「打てた」の合図で:
   - `git diff` で採点（採点モードと同じ3分類）
   - 対象のテストを実行（backend: `cd backend && npm run test -- --testPathPattern=<対象>` / frontend: `cd frontend && npm run test -- <path>`）
   - 3行ログ（写した範囲 / 一番「へぇ」だったこと / まだ分からないこと）を本人に書いてもらい、create-memo スキルで daily ノートへ追記する
   - `git add -A && git commit -m "chore(shakyo): dayN <対象>"`（shakyo ブランチ上で）
   - 次回のメニューを一言予告。このあと通常の開発をするなら `git switch main` を案内する

## 補足

- 採点基準は分岐時点の main（`git diff` の比較先）。main が進んでも shakyo ブランチは追従不要
- 注釈コメントが diff に残るのは正常（学習成果物）。shakyo ブランチは**マージしない**
- Module 1 完了後は、計画書の「Module 2 以降の候補」を一緒に日割り化する（このときだけ計画書の編集を提案してよい）
